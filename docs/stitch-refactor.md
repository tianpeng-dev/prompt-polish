## 组件与行为契约

- 单文本框；主编辑、方法菜单、设置、错误详情共享颜色、字体、按钮与焦点规则。
- 主窗固定 460 × 176。菜单／设置／详情只通过有限视图标识请求主进程调整尺寸，不允许 Renderer 提交坐标。
- 方法目录仅包含十二个方法，不保存处理模式。点击方法通过 `thinking.copy` 白名单 IPC 在主进程本地组合并复制，正文与光标保持原样；空白输入复制可直接使用的通用模板。
- Trae 输入上限 2000 字符；思考方法使用当前可见正文，允许较长的优化结果，组合提示词上限 10000。代码、路径、数字与占位符逐字保留，超限在写入剪贴板前拒绝。
- 方法复制结果仅在内存保存，支持只读预览。普通优化继续原位替换正文，并保留一次编辑撤销；快捷键与托盘优化剪贴板始终调用 Trae。
- 方法目录与编辑器在同一窗口切换；关闭后保留正文、光标及滚动位置。方法复制成功后，未置顶窗口显示 800ms 确认后隐藏；继续输入、鼠标操作、打开其他页面或重新唤起窗口会取消这次自动隐藏。
- 请求进行时输入与方法选择锁定；响应只应用于原始 revision，后来编辑的内容保留。
- 手动优化不自动修改剪贴板；点击方法立即复制，成功反馈提供查看与撤销。复制、优化与撤销共用主进程剪贴板归属记录；重复复制相同内容保留原撤销记录，预览重新复制返回实际操作 ID。撤销检查当前内容与操作 ID，不覆盖后来复制的内容。
- Settings schemaVersion 2、Bundle ID、应用数据目录保持兼容。保存失败恢复原值并提供重试，快捷键冲突保留原设置。
- macOS 在项目内独立 APFS 工作卷签名；ZIP 解压验证会清理验证目录由本机 File Provider 附加的文件属性，再校验完整签名。最终 ZIP 内容不作改写，输出通过验证后原子替换。
- 登录取消保留草稿与撤销内容。普通优化未登录时承接官方登录；本地方法不需要登录或联网。
- 全部交互控件 no-drag；顶部和外边缘使用原生拖动；焦点可见、弹层焦点循环、关闭恢复焦点、reduced-motion。
